# ZakFit

Nutrition and fitness tracking app for iOS, built with SwiftUI, a Vapor REST API and MariaDB.

Work in progress — final delivery on December 11, 2026.

## Repository layout

| Folder | Content |
|---|---|
| `docs/` | Data dictionary, Merise models (MCD, MLD, MPD), UML diagrams, SQL script |
| `backend/` | Vapor API (JWT, Fluent, raw SQL for statistics), OpenAPI documentation |
| `ios/` | SwiftUI app (MVVM), HealthKit, Swift Charts |
| `backoffice/` | Admin web interface (HTML, CSS, vanilla JavaScript) |
